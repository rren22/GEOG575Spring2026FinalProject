About

This project is a personal visualization of campus study spots, designed to help users quickly find places suitable for studying. The locations displayed combine public listings with manual edits and additions by the project team.

Data sources & edits

Primary source: buckygrades.com/study. The project team has added new attributes and corrected a small number of records (for example, missing photos, normalized names, or slight coordinate adjustments) to improve coverage and clarity.

Ratings

Ratings reflect the author's subjective impressions, considering factors such as quietness, convenience (seating/outlets), and comfort. Values use low/medium/top tier. Ratings are qualitative and not instrumented measurements.

Limitations

Data shown are static snapshots and not live. Dynamic attributes such as occupancy and noise should be treated as illustrative; please verify conditions on-site.
